# Architecture decision records

Short records of consequential decisions, in the format from [ARCHITECTURE.md §14](../ARCHITECTURE.md#14-architecture-decision-records): context, decision, alternatives, consequences, date and status.

To change a decision, add a new ADR that supersedes the old one and update the old one's status. Do not rewrite history.
